# PlayHT (play-ht)

PlayHT is an AI voice generation and TTS platform with hundreds of voices, voice cloning, and a realtime conversational voice API (Play 3.0 mini, PlayDialog). The PlayHT REST API exposes voice synthesis, voice cloning, streaming, and language translation.
